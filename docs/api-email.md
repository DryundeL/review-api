# Почта и вход по коду (для фронта)

Почта привязывается к уже существующему Telegram-аккаунту. Отдельной регистрации нет. После подтверждения тот же адрес входит кодом и получает тот же JWT, что `POST /v1/auth/telegram`.

Адрес хранится в нижнем регистре, без пробелов, 3–254 символа, один `@`. `User@Example.com` и `user@example.com` — один адрес.

Код — 6 цифр, живёт 10 минут. Пять неверных попыток сжигают его. Повторная отправка на тот же адрес раньше чем через 60 секунд — **429**.

Ошибки:

```json
{ "error": { "code": "EMAIL_CONFLICT", "message": "email already in use" } }
```

| Код | `error.code` | Когда |
|---|---|---|
| 400 | `VALIDATION_ERROR` | битый JSON |
| 401 | `UNAUTHORIZED` | нет Bearer или неверный код |
| 409 | `EMAIL_CONFLICT` | адрес уже у другого пользователя |
| 422 | `VALIDATION_ERROR` | формат почты |
| 429 | `RATE_LIMITED` | код на этот адрес уже отправлен меньше минуты назад |
| 503 | `EMAIL_UNAVAILABLE` | письмо не ушло |

---

## Свой профиль

`GET /v1/profile` и `GET /v1/profiles/{id}` при `isMe: true` добавляют поле. Чужой профиль его не содержит.

```json
{ "email": "user@example.com" }
```

Пустая строка не приходит: почта ещё не привязана.

---

## Привязать

Auth: **Bearer обязателен**.

### `POST /v1/email`

```json
{ "email": "user@example.com" }
```

| Код | Тело | Смысл |
|---|---|---|
| 202 | `{ "expiresIn": 600 }` | код отправлен, ждать письмо |
| 200 | пусто | этот адрес уже привязан к текущему пользователю, письмо не отправлялось |

Старый адрес остаётся, пока новый код не подтверждён.

### `POST /v1/email/confirm`

```json
{ "code": "123456" }
```

**204** — почта записана. Дальше её видно в своём профиле. Неверный, просроченный и уже сожжённый код — один **401**.

---

## Войти

Без сессии. **202 не значит, что письмо ушло**: неизвестный адрес отвечает так же, как известный.

### `POST /v1/auth/email`

```json
{ "email": "user@example.com" }
```

**202** `{ "expiresIn": 600 }`.

### `POST /v1/auth/email/confirm`

```json
{ "email": "user@example.com", "code": "123456" }
```

```json
{ "token": "<jwt>" }
```

Неизвестный адрес, неверный код и сожжённый код — один **401**. Токен кладётся так же, как после входа через Telegram.
