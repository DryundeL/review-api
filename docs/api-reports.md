# Reports (для фронта)

Жалобы на опубликованные обзоры. При достижении порога уникальных жалобщиков обзор автоматически уходит в `draft` и пропадает из лент/публичных списков.

Порог: env `REPORT_HIDE_THRESHOLD` (дефолт `10`). Меняется без правки кода, нужен restart API.

## Поток

```
1. GET /v1/report-reasons
   → code + label для селекта в UI

2. POST /v1/reviews/{reviewId}/reports   # Bearer
   body: { "reasonCode": "spam" }
```

Один пользователь = один репорт на обзор. Повтор → `409 ALREADY_REPORTED`.

---

## Справочник причин

### `GET /v1/report-reasons`

Auth: **не нужен**. Только активные причины, по `sortOrder`.

```json
{
  "items": [
    { "code": "spam", "label": "Спам" },
    { "code": "abuse", "label": "Оскорбления / токсичность" },
    { "code": "spoiler", "label": "Спойлеры без предупреждения" },
    { "code": "wrong_title", "label": "Неверный тайтл / обман" },
    { "code": "illegal", "label": "Запрещённый контент" },
    { "code": "other", "label": "Другое" }
  ]
}
```

В UI показывать `label`, в `POST` отправлять `code`. Список может расшириться на бэке — не хардкодить коды на клиенте, кроме fallback.

---

## Создать жалобу

### `POST /v1/reviews/{reviewId}/reports`

Auth: **Bearer обязателен**.

```json
{ "reasonCode": "spam" }
```

**201:**

```json
{
  "id": "uuid",
  "reviewId": "uuid",
  "reasonCode": "spam",
  "createdAt": "2026-10-19T20:00:00.123456789Z"
}
```

Если жалобщиков стало ≥ порога — обзор снимается в той же TX (`status → draft`). В ответе отдельного флага нет: после успешного POST при необходимости перезапросить обзор/ленту.

| Код | Когда |
|---|---|
| **401** | нет / битый Bearer |
| **403** | жалоба на **свой** обзор |
| **404** | нет обзора / не `published` / битый uuid |
| **409** `ALREADY_REPORTED` | этот юзер уже жалобвался на этот обзор |
| **422** | пустой / неизвестный / неактивный `reasonCode` (`field: reasonCode`) |
| **400** | битый JSON body |

---

## Поведение для UI

- Кнопка «Пожаловаться» только на **чужих** опубликованных обзорах.
- После `409` — показать «Вы уже отправляли жалобу», не давать повторять.
- После `201` — закрыть форму; не ждать отдельного события снятия.
- Снятый обзор исчезает из feed / public lists; у автора снова виден как черновик в `/profile/reviews`.
