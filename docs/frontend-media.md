# Загрузка изображений

`POST /v1/media/images` — только с авторизацией (`Authorization: Bearer …`).

Тело — `multipart/form-data` с одной частью `file`. Имя файла и `Content-Type` части
сервер не учитывает: формат определяется по содержимому.

Ограничения:

- форматы: JPEG, PNG, WebP; GIF и SVG отклоняются;
- размер файла — не более 300 КБ (307 200 байт);
- ширина и высота — от 1 до 4096 px;
- не более 120 загрузок в час на пользователя (`MEDIA_UPLOADS_PER_HOUR`).

Метаданные (EXIF с геолокацией, XMP, текстовые чанки PNG) сервер удаляет без
перекодирования, поэтому сохранённый файл может быть немного меньше исходного.

Ответ `201`:

```json
{ "id": "uuid", "url": "/storage/images/<uuid>.webp", "contentType": "image/webp", "width": 640, "height": 480 }
```

`id` передаётся в шаблон списка. Загрузка, которая за 24 часа ни к чему
не привязана, удаляется автоматически.

| Код | Когда |
|---|---|
| 400 `BAD_REQUEST` | тело не `multipart/form-data` |
| 401 `UNAUTHORIZED` | нет входа |
| 413 `PAYLOAD_TOO_LARGE` | файл больше 300 КБ |
| 415 `UNSUPPORTED_MEDIA_TYPE` | не JPEG, PNG или WebP |
| 422 `VALIDATION_ERROR` | нет части `file` (`details.field = "file"`), файл повреждён или размеры вне диапазона (`details.reason = "dimensions"`) |
| 429 `RATE_LIMITED` | превышена квота загрузок |

Проверять размер и формат на клиенте до отправки стоит для удобства пользователя;
сервер всё равно проверяет их сам.
