# План реализации комментариев

Согласованная спецификация: `SPEC-comments.md`.

1. [x] Создание комментария: доменная валидация, схема, транзакция с outbox,
   репозиторий, HTTP и подключение модуля. Проверка: unit и HTTP-тесты.
2. [x] Загрузка корней/ответов: keyset-курсор, ограниченная страница,
   `hasReplies` без рекурсивного обхода. Проверка: unit и PostgreSQL-тесты.
3. [x] Уведомления: consumer, два типа настроек, адресация комментария в inbox,
   стабильные ID при повторной доставке. Проверка: consumer и settings-тесты.
4. [x] Проверка интеграции: миграции up/down, ограничения и пагинация в PostgreSQL,
   `go test ./...`, `go vet ./...`, `go build ./cmd/...`, документация фронтенда.

Зависимости: 1 → 2; 1 → 3; 2 + 3 → 4. Новых библиотек нет.

Проверено на временном PostgreSQL 16: вложенность, границы страниц, атомарность
outbox, гонка создания со скрытием отзыва, настройки и дедупликация уведомлений,
ошибка Telegram, миграции up/down. Контрольная инверсия выбора типа уведомления
обнаруживается интеграционным тестом; исходный код восстановлен.
Миграции рабочей БД и код другого репозитория фронтенда не изменялись.
